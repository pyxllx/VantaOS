# VantaOS Security Center

Status: planned wrapper app.

1.0 scope:

- Firewall controls through UFW/GUFW or KDE firewall integration.
- Password manager entry point through KeePassXC.
- TOTP entry point through GNOME Authenticator or equivalent.
- Update and firmware status links.
- Disk encryption explanation/status from installer choices.
- Recovery documentation.

Not 1.0 scope:

- Custom password vault.
- Custom 2FA storage.
- Custom security daemon.
