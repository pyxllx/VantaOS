# VantaOS Gaming Center

Status: planned wrapper app.

VantaOS Gaming Center should not replace proven Linux gaming tools. It should
unify them behind one beginner-friendly interface.

1.0 scope:

- Launch Steam, Heroic, Lutris, ProtonUp-Qt, OBS Studio, OpenRGB, LACT/CoreCtrl where available.
- Show driver status and basic GPU/CPU information.
- Provide MangoHud and GameMode shortcuts.
- Link to controller settings.
- Use existing system tools for fan and GPU control.

Not 1.0 scope:

- Custom Proton implementation.
- Custom GPU driver stack.
- Custom fan-control backend.
- Custom RGB protocol implementation.
