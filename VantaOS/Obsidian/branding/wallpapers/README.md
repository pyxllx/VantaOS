# Wallpapers

VantaOS Obsidian wallpaper direction:

- Dark, clean, premium, slightly futuristic.
- Avoid macOS-style landscape clones.
- Avoid single-color purple/blue gradient overload.
- Ship static wallpapers first.
- Add live wallpaper support through existing tools only: `wallpaper-engine-kde-plugin`, `mpvpaper`, or Hidamari.

Expected install path:

```text
/usr/share/wallpapers/vantaos
```
