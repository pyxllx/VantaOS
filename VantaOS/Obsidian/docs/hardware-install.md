# Installing On Real Hardware

VantaOS Obsidian is not ready for daily-driver hardware installs until VM
testing passes consistently.

## Before Installing

- Back up important data.
- Test live USB boot first.
- Confirm Wi-Fi, Bluetooth, display, audio, and suspend/resume.
- For NVIDIA systems, test both Wayland and X11.
- Keep Ubuntu 24.04 install media available as a fallback.

## Recommended Installer Defaults

- UEFI install.
- Full disk encryption for laptops.
- Automatic partitioning for beginners.
- Manual partitioning for dual-boot and advanced users.
- Wayland default, X11 fallback.

## Hardware Validation

Track:

- CPU generation.
- GPU model and driver.
- Wi-Fi chipset.
- Audio chipset.
- Laptop model.
- Suspend/resume behavior.
- External monitor behavior.
- High refresh rate behavior.
- Fractional scaling behavior.
