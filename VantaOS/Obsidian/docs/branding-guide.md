# Branding Guide

VantaOS should feel dark, fast, premium, smooth, and slightly futuristic without
becoming a macOS or Windows clone.

## Visual Rules

- Dark base, high contrast text.
- Use accent color sparingly.
- Rounded UI, but avoid oversized pill everything.
- Subtle blur only where it improves depth.
- Keep animations quick.
- Avoid heavy effects that push idle RAM above target.
- Avoid one-note purple/blue gradient themes.
- Keep GTK and Qt apps visually aligned.

## Main Menu Direction

Use KDE's launcher as the 1.0 foundation.

- Super key opens launcher.
- Search focused by default.
- Profile-aware favorites.
- Power/session controls visible.
- No ads, recommendations, or clutter.
- Dark translucent command-center feel.

Do not build a custom launcher for 1.0.

## RAM Target

- Clean idle: 1.1 GB to 1.5 GB.
- Gamer/Work idle: 1.3 GB to 1.8 GB.
- Investigate anything above 2 GB idle.
