# Release Roadmap

## VantaOS 1.0 Obsidian

Goal: bootable Ubuntu 24.04 LTS-based KDE distribution with real profile
manifests, VantaOS branding, and a maintainable ISO build path.

Must have:

- Bootable ISO.
- Clean/Gamer/Work profiles.
- KDE Plasma desktop.
- Wayland default, X11 fallback.
- Calamares installer.
- VantaOS branding and defaults.
- KeePassXC and TOTP app.
- OpenRGB in Gamer.
- OBS Studio in Gamer.
- Build and install documentation.

Should have:

- Calamares GUI profile selection.
- Themed Discover and Plasma System Monitor.
- VantaOS SDDM and Plymouth polish.
- Basic Gaming/Work/Security Center launchers.

Not for 1.0:

- Custom desktop environment.
- Custom compositor.
- Custom settings framework.
- Custom package manager.
- Custom live wallpaper renderer.
- SignalRGB as a default dependency.

## VantaOS 1.1

- Improve installer profile chooser.
- Add lightweight VantaOS Center frontends.
- Add wallpaper/live wallpaper settings wrappers.
- Add more theme consistency work for GTK apps.
- Add hardware validation matrix.

## VantaOS 2.0

- Rebase onto the next mature Ubuntu LTS after ecosystem stabilization.
- Revisit HDR/VRR controls as KDE and driver support improves.
- Consider custom QML launcher only if KDE defaults become a real blocker.
